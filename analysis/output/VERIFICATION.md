Notes

- TMTF: the PDF was made from the records up to 2026-11-03 (142 runs); the eight 2026-11-04 runs are left out (`PDF_LAST_DATE` in tmtf.py). Run thresholds are rounded to 0.01 dB as the app stores them before averaging.
- SMRT: run thresholds are rounded to 0.0001 RPO as the app stores them; the PDF SDs were computed from those values.
- SRD: reversal densities are summed in integer milli-RPO as in the app (0.96025 -> 0.9603).
- SMD: the PDF rounds exact halves up (21.325 -> 21.33), so this comparison rounds half up; the default binary formatting would print 21.32.
- English and Korean PDFs carry the same numbers; values were taken from the English text layer.
- Not compared (not computed from data): design constants in the methods text, literature reference lines, the GDT sample-quantisation example, and the PDFs' own source hashes.
